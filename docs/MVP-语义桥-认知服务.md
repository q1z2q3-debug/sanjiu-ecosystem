# 三元九维 19683 · 认知坐标服务 + 语义桥（5 域全景）

> 目标：把 19683 从「符号库」升级为「Agent 认知引擎」，兑现"既能定位又能泛化"。
> 本版本交付**台阶一（认知坐标服务）+ 台阶二（语义桥·5 域全景 + 深度卦典）**。

---

## 一、核心假设

**"19683 是通用认知坐标"** —— 各领域仓共享同一状态空间，因此**同编号卦的"处境含义"
应跨领域一致**，只是各领域用自己的语言表达。本版把验证从 3 域扩到 **5 域 + 深度卦典**。

## 二、架构（沿「形式统一 + 语义自适配」）

```
sanjiu-core（唯一数学底座，不动）──算子/索引/距离/等价组──┐
                                                          │
服务层 service/bridge.py                                  │
  台阶一 认知坐标原语   encode / search / transform         │
  台阶二 语义桥         fingerprint + 五域规则 + bridge ── 各域 manifest 位权映射
                                                          │
五域解读（同一编号卦，各用本域语言说同一件事）               │
  D/R/T    体用变    洛书九宫    小六壬    疗愈             │
  + 深度象义（主仓人类卦典 19683 全，按 idx 查：卦名/卦辞/启示）
```

- **结构指纹**（跨域共享锚点）：阳/阴/中计数 + 倾向标签（显·进/隐·守/枢·待/偏显·渐/
  偏隐·渐守/衡·中 + 张力高）。
- **位权映射**：各域用自身 `bit_weight_map` 转 core 向量到域内序（正/反向两组）。
- **深度象义**：接入主仓 `sanjiu_quanji_human.json`（19683 条人类卦典），同一编号卦
  附卦名/卦辞/启示 —— 让"回归正轨人类语言解读"落地。

## 三、认知坐标服务原语（台阶一）

| 原语 | 作用 |
|---|---|
| `encode(自然语言) → 9维向量` | 状态写入 19683 坐标 |
| `search(向量, Top-N)` | 欧氏距离邻域定位，附错/综/错综/互/变推演 |
| `transform(卦)` | 全套结构变换 |
| `render(域, 卦)` | 单域确定性解读 |
| `bridge(卦) → 五域解读 + 深度象义` | 同一坐标多语言（核心产品） |

## 四、五域全景演示（确定性，从卦象义长出来）

| 编号 | 卦 | 结构倾向 | 深度象义 |

## 五、一致性验证结果（5 域 + 深度象义）

- **机械一致性：12/12** —— 抽样覆盖全倾向类，每卦五域共享同一结构倾向。
- **深度象义对照：抽查代表卦，卦典（卦名/启示）与五域解读完全同处境**。
- **自然语言定位**：输入"根基稳固，主动进取，增益丰盈，时势顺遂"→ 向量
  `(0,1,0,1,1,0,0,0,1)` → Top1 卦 12353（阳·悔亡·察动度卦），五域解读贴合输入。

## 六、核心假设验证结论

✅ **5 域 + 深度卦典层成立**：同一编号卦在 D/R/T · 体用变 · 洛书九宫 · 小六壬 · 疗愈
五域解读**且深度卦典**都指向同一处境。各域侧重不同（体/承载/中宫/吉凶宫/疗愈维），
是**语义自适配（位权映射 + 域语言）**的应有之义，而非不一致。
"19683 作为通用认知坐标"得到**多域多语言 + 人类卦典三重印证**。
