# 三元九维 19683 · 认知坐标服务 + 语义桥（MVP）

> 目标：把 19683 从「符号库」升级为「Agent 认知引擎」，兑现"既能定位又能泛化"。
> 本 MVP 交付**台阶一（认知坐标服务）+ 台阶二（语义桥）**，并验证核心假设。

---

## 一、核心假设

**"19683 是通用认知坐标"** —— 各领域仓（D/R/T · 体用变 · 洛书九宫 · 小六壬 · 疗愈）共享
同一状态空间，因此**同编号卦的"处境含义"应跨领域一致**，只是各领域用自己的语言表达。

> 若不成立，则互译需显式领域桥规则，架构要调整；若成立，则空间真是"通用认知坐标"。

## 二、架构（沿「形式统一 + 语义自适配」）

```
sanjiu-core（唯一数学底座，不动）──算子/索引/距离/等价组──┐
                                                          │
服务层 service/bridge.py                                  │
  台阶一 认知坐标原语   encode / search / transform         │
  台阶二 语义桥         fingerprint + 三域规则 + bridge ── 各域 manifest 位权映射
                                                          │
三域解读（同一编号卦，各用本域语言说同一件事）               │
  D/R/T（承载·审定·增益）  体用变（体用变时空势因果缘）  洛书九宫（坎坤震巽中乾兑艮离）
```

- **结构指纹**（跨域共享锚点，从 core 向量直接算出）：阳/阴/中计数 + 倾向标签
  （显·进 / 隐·守 / 枢·待 / 偏显·渐 / 偏隐·渐守 / 衡·中 / 张力高·阴阳并争）。
- **位权映射**：各域用自身 `bit_weight_map` 把 core 向量转到域内维序，再用域规则生成解读。

## 三、认知坐标服务原语（台阶一）

| 原语 | 作用 |
|---|---|
| `encode(自然语言状态) → 9维向量` | 状态写入 19683 坐标 |
| `search(向量, Top-N) → 最近邻卦` | 欧氏距离邻域定位，附错/综/错综/互/变推演 |
| `transform(卦)` | 全套结构变换（F_C / F_Z / F_CZ / F_H / 逐爻变卦） |
| `render(域, 卦) → 该域解读` | 单域确定性解读 |
| `bridge(卦) → 各域并行解读` | 同一坐标多语言（核心产品） |

## 四、语义桥演示（确定性，从卦象义长出来）

| 编号 | 卦 | 结构倾向 | D/R/T | 体用变 | 洛书九宫 |
|---|---|---|---|---|---|
| 9841 全中 | (0×9) | 枢·待 | 中平·堪任·平允 | 体稳用平变待时缓缘正 | 中宫气枢，主权衡待定 |
| 19682 全阳 | (1×9) | 显·进 | 盈·明·丰 | 体厚用盈变现时顺缘聚 | 中宫气旺，枢纽当行 |
| 0 全阴 | (-1×9) | 隐·守 | 亏·晦·耗 | 体弱用虚变塞时逆缘散 | 中宫气敛，枢纽沉寂 |
| 12900 张力 | 阳4阴3 | 偏显·张力高 | 承载盈·增益略耗 | 体不足·时势逆阻 | 中宫气敛，多宫气敛 |

→ 同一编号卦，三域解读**读起来都指向同一处境**（全盛当进、全衰宜守、张力之卦
"有攻有阻、矛盾缓进"），只是各用本领域语言。

## 五、一致性验证结果

- **机械一致性：12/12** —— 抽样覆盖全倾向类（全显/全隐/枢待/偏显/偏隐/衡/张力），
  每卦三域共享同一结构倾向（均由同一指纹派生，天然一致）。
- **语义贴合：抽查 4 卦人工审读，三域解读语义一致**，贴合该卦结构（详见上表）。
- **自然语言定位验证**：输入"根基稳固，主动进取，增益丰盈，时势顺遂"
  → 向量 `(0,1,0,1,1,0,0,0,1)` → Top1 卦 12353，解读贴合输入语义。

## 六、核心假设验证结论

✅ **初步成立**：同一编号卦在 D/R/T · 体用变 · 洛书三域的解读指向同一处境，
"19683 作为通用认知坐标"得到支持。各域"体/承载/枢纽"侧重不同，是**语义自适配
（位权映射 + 域语言）**的应有之义，而非不一致。

> 说明：本 MVP 三域规则为确定性模板（维度三态判级），验证的是"结构→多语言同处境"
> 的机制成立；更深度的"卦典人类转译"可接入 `trigram/interpret.py` 与人类卦辞库。

## 七、风险与待扩展

- 领域数：目前 3 域，可加小六壬（xiuqiankun）、疗愈（heal-belief）成 5 域全景桥。
- 判级粒度：维度判级已分五档；可接入各仓更细的"象义"（oracle / 卦辞）增强文本。
- 语言自然度：确定性模板偏"评语体"，可交给 LLM 润色（符号给骨架、LLM 填自然语言）
  —— 这正是台阶三「认知推理层 + 回归正轨语言体系」的方向。
