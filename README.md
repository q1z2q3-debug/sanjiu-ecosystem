# 三元九维 · 生态中枢（sanjiu-ecosystem）

> 单一入口，统览整个「三元九维 19683 认知空间」生态。
> 设计原则：**形式统一 + 语义自适配** —— 数学底座唯一，领域语义各自适配。

```
              ┌─────────────────────────────┐
              │   sanjiu-core（形式层，唯一底座） │
              │  3⁹=19683 · 平衡三态 · 错综互变  │
              │  算子 · 索引 · 校验 · manifest   │
              └──────────────┬──────────────┘
                             │ 语义自适配（各仓 manifest）
   ┌──────────┬──────────┬───┴──────┬───────────┬──────────┐
   │ 诗词/卦典 │  占卜     │  中医      │  量化/交易 │  Agent记忆 │
   └──────────┴──────────┴──────────┴───────────┴──────────┘
```
